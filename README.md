DogTracks — Behavior & Training Tracker
DogTracks is a web application designed to help dog owners, trainers, and shelters track training sessions, record behaviors, identify triggers, and visualize long‑term progress. Many owners struggle to stay consistent with training or remember what caused certain behaviors. DogTracks solves this by providing structured logging, multi‑dog profiles, and clear visual insights that reveal patterns over time. Built using modern web technologies and Firebase, the app is lightweight, accessible, and designed for quick, intuitive interaction.

Project Setup & Installation
- To run the DogTracks web application, ensure the following tools and services are set up:
- A Firebase project created in the Firebase Console
- VS Code or any preferred code editor
- Node.js installed (for Firebase tools or server‑side scripts)
- Git installed for version control

Installation Steps
1. Clone the repository
bash
git clone <your-repo-url>
cd dogtracks_web
2. Install dependencies (if using Node.js tools)
bash
npm install
3. Connect Firebase
Add your Firebase configuration to your project’s JavaScript initialization file
Ensure Firestore, Authentication, and Hosting are enabled in the Firebase Console
Use your team’s shared Firebase project credentials
4. Run the application
Since DogTracks is a web application, it can be run by:
- Opening the project folder in VS Code
- Using a local development server
- Or deploying through Firebase Hosting when ready
